# ارائهٔ ابوحنیفه دینوری و کتاب النبات

پاورپوینت ۱۴ اسلایدی دربارهٔ **ابوحنیفه احمد بن داود بن واند دینوری**، دانشمند ایرانی‌تبار قرن سوم هجری و کتاب «النبات».

## ویژگی‌ها
- ۱۴ اسلاید (۱۲ اسلاید محتوایی + دو سؤال تستی + یک سؤال تشریحی)
- فونت **B Nazanin** و چینش کامل **راست‌به‌چپ (RTL)**
- پالت کرم و سبز با جزئیات طلایی به سبک نسخه‌خطی
- تصویرسازی هنری پرتره + یادداشت‌های سخنران برای همهٔ اسلایدها (پاسخ سؤال‌ها در یادداشت‌ها)
- منبع اصلی: دانشنامهٔ ایرانیکا
